# GRID currency

A fictional five-note currency for a creative world, designed as one system. Each note states one design value as a geometric rule, and each note ships with a blueprint that shows how it was made.

## Overview

| Note | Value | Symbol | The rule |
| --- | --- | --- | --- |
| 1000 | Creativity | Unfold | Every square turns 45 degrees and grows by the square root of two from one shared corner, so the area doubles each quarter turn. |
| 500 | Clarity | Resolve | Eight stripes close their gaps in stages, 8, 4, 2, 1, until the last bar is exactly as tall as the numerals. |
| 200 | Empathy | Common ground | The grid inverted in a circle, so two perspectives meet at one contact point. |
| 100 | Craft | Depth | A carpet divided by three, three times, which leaves 73 holes and a stitch in each. |
| 50 | Impact | Ripple | A dot lattice reshaped by a decaying wave whose centre is the counter of the zero in "50". |

The output is ten SVG files: a banknote of 1600 by 750 units, 160 by 75 millimetres, and a 2400 by 1600 blueprint for each denomination, plus a page that browses them all.

## The idea

Each note carries one design value (creativity, clarity, empathy, craft, impact) and expresses it as a single geometric rule. Every note shares one architecture, a 20 by 8 module grid, eight named layers in a fixed order, seven colour roles with flat fills only, and two typefaces, so what differs between notes is the geometry.

## Process

The notes are generated by script. A small toolkit holds the pattern generators, the shared note architecture and the blueprint builder, and each symbol's geometry is defined once and reused by both the note and its blueprint. A validator fails any note that uses a colour outside its palette, leaves a colour role unused, or uses a gradient, filter, mask, opacity or raster image. Each blueprint has nine panels, from the final note through the wireframe and the symbol construction to the colour-separation plates and measured colour coverage.

## Result

Five notes and five blueprints in a public repository, committed on 24 November. There is no hosted version linked yet.

## Notes

This entry is written from the project's README, which lists what is not verified. The numerals and titles use Impact, which has to be installed, otherwise the text falls back to a wider sans. The files were checked in Chromium only, and importing them into Figma or Illustrator was not tested, with the pattern fills the most likely place for those tools to differ. The work is on a branch of the Ideas repository (`claude/grid-currency-design-nw5tkr`) that is not yet merged into its default branch, so the source link points at that branch.
