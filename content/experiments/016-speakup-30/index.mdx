# SpeakUp 30

A private, 30-day speaking coach for one person. It is a working web app, not a mock-up: it runs a daily session, reads scripts on a teleprompter, records you and builds a report from what you said. There is no account, no server and no tracking.

## Overview

The first screen says Welcome to SpeakUp 30 with one button, Start Day 1. A session is a two-minute vocal warm-up, the teleprompter, guided speaking, a challenge question and a reflection. The app also has a dashboard with streaks and a timeline of the 30 days, a view of every answer and its report, progress charts by week, a reflection journal, and settings with backup and restore.

Across the thirty days the session grows from 20 to 30 minutes and the support is taken away week by week: full scripts first, then script plus bullets, then key phrases only.

## The idea

The README's rule is that nothing is faked. The app measures pace, pauses and filler words from what you actually said and recorded, and says so when it does not have enough data to score something.

## Process

The teleprompter scrolls at a words-per-minute pace with real pauses, shows cues that are visually unlike the script (pauses, emphasis and delivery tips) and never reads them aloud, and splits scripts into speaking chunks. Anything personal in the scripts is a placeholder with coaching, so the scripts contain no invented results.

The analysis follows a rule: nothing is faked, and a score is "Not scored" when there is not enough data. Pace is words divided by speaking time, pauses are counted from the microphone level, and filler words are counted by context, so "I would like to" is not a filler but "it was, like, hard" is. Every report has a section that shows the basis of each number. An optional AI review sends only the transcript text, never the audio, and only if you add your own API key in settings.

## Result

A static web app in a public repository. It installs on a phone's home screen and its shell works offline. A published copy is linked from this page. Recordings, progress and text stay on the device, and a backup is one JSON file.

## Notes

This entry is written from the project's README. In Chrome and Edge, live transcription uses the browser's own speech service, which sends audio to the browser maker's servers, and it can be turned off in settings. The published copy is a single-file build in which the optional AI review is off and speech comes from the viewer's dictation. The optional AI review path was tested only up to the request, because the build environment had no outbound route. The work is on a branch of the Ideas repository (`claude/speakup-30-speaking-coach-e3e7co`) that is not yet merged into its default branch, so the source link points at that branch.
