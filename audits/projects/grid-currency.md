## What changed

New work on an unmerged branch of the Ideas repository, one commit on 2026-11-24. A fictional five-note currency designed as one system: each note expresses a design value as a geometric rule, with a blueprint showing how it was built. Ten SVG files plus a viewer page.

## Why it changed

Unknown. The README frames the notes as one design system with a value, a principle and a rule per denomination.

## Design / UX changes

Notes of 1600 by 750 units on a shared 20 by 8 module grid with eight named layers, seven flat colour roles, two typefaces and security-inspired details; blueprints of nine panels each.

## Technical changes

Node build scripts that generate the SVGs, a toolkit of pattern generators, and a validator that rejects colours outside a note's palette and any gradient, filter, mask, opacity or raster.

## Experiment insight

Tests whether a strict system can carry five visually distinct objects whose only difference is geometry.
